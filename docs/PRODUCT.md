# Product

## Purpose

School Accounting is a forthcoming system to help school staff carry out accounting work in alignment with the School Accounting Manual 2076.

## Product principles

- Make routine accounting tasks understandable for non-technical users.
- Support accurate, traceable financial record-keeping.
- Turn verified manual requirements into practical workflows and safeguards.
- Keep the initial product focused; expand only when requirements and user needs justify it.

## Users

Primary users and their responsibilities will be documented as the manual is specified and workflows are researched.

## Scope status

No application features have been specified or implemented yet.

## Source material

The authoritative reference is `reference/school guidelines.pdf` (School Accounting Manual 2076). This document does not restate unverified manual content.
